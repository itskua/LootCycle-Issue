# LootCycle

Issue tracker and changelog for LootCycle.

- Download: https://modrinth.com/plugin/lootcycle
- Changelog: [CHANGELOG.md](CHANGELOG.md)
- Issues: https://github.com/itskua/LootCycle-Issue/issues

## Compatibility

- Server: Paper, Folia, Purpur, Leaf (Minecraft 26.3)
- Java: 25+

Spigot, Fabric, and Forge are not supported.

## Reporting a bug

Open an issue with your server software/version, LootCycle version, what happened, and any console errors.
